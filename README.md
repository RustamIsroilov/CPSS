# CPSS — AAOIFI шариат стандартлари курси

AAOIFI шариат стандартлари бўйича ўзбекча (кирилл) ўқув платформаси. CPSS (Certificate of Proficiency in Shari'ah Standards) имтиҳонига тайёргарлик учун.

Битта HTML файл — сервер, база ва интернет керак эмас. Ташқи боғлиқлик йўқ, offline ишлайди.

## Тузилма

Расмий CPSS ҳафталик ўқув режасига мослаштирилган **28 та ҳафта**. Дарслар шанба ва якшанба, ҳафта ичи такрорлаш, жума куни имтиҳон.

| Кун | Нима бўлади |
|---|---|
| Шанба | Ўша куннинг стандарти (1–2 та) |
| Якшанба | Ўша куннинг стандарти (1–2 та) |
| Душанба | Ҳафта атамалари флешкартаси |
| Сешанба | Ҳафта стандартларидан 15 та ҳукм савол |
| Чоршанба | Хатолар устида ишлаш |
| Пайшанба | Ўрганилган ҳамма нарсадан 20 та аралаш савол |
| Жума | Имтиҳон — ҳафталик 20 савол; блок якунида 40 савол |

Ҳар бир стандарт алоҳида дарс бўлиб, тўрт босқичдан иборат: **ўқиш → флешкарта → луғат машқи → тест**. Дарс тестидан 90% олинмаса ҳафтанинг кейинги дарси, жума имтиҳонидан 90% олинмаса кейинги ҳафта очилмайди.

Ўн икки дарсда қўшимча **«Амалиёт»** блоки бор: битим босқичлари, рақамли ҳисоб-китоб мисоллари, хатар жадваллари ва кўп бериладиган саволлар.

## Модуллар ва имтиҳондаги оғирлиги

1-модул — Шариат асослари ва шартнома ҳуқуқи (7%)
2-модул — Молия шартномалари, 2.1–2.7 блоклар (71%)
3-модул — Ислом банкчилиги (7%)
4-модул — Молия бозорлари ва такофул (15%)

## Сайт қилиб чиқариш (GitHub Pages)

1. Бу репозиторийни GitHub'га юкланг
2. **Settings → Pages → Source:** `main` бранчи, `/ (root)` папкаси
3. Бир-икки дақиқада `https://<фойдаланувчи>.github.io/<репозиторий>/` манзилида очилади

Файл 3 MB, лекин GitHub Pages уни сиқиб узатади — амалда ~520 KB.

## Прогресс

Прогресс браузер хотирасида сақланади: дарс босқичлари, имтиҳон натижалари, ҳафта ичи вазифалари, хатолар банки. Бошқа қурилмага кўчириш учун «Прогресс» бўлимидан файлга юкланг ва ўша ерда тикланг.

## Манбалар ва эслатма

Конспектлар AAOIFI Shari'ah Standards расмий инглизча матни асосида ўқув мақсадида қисқартириб тайёрланган. **Расмий ҳужжат ўрнини босмайди** — ихтилофли масалаларда стандартнинг ўзига мурожаат қилинг: <https://aaoifi.com/e-standards/?lang=en>

«Амалиёт» блоклари ислом молияси бўйича ўзбекча тренинг материаллари асосида тузилган.

Имтиҳон инглиз ёки араб тилида топширилади — ўзбекча конспект тушунишни тезлаштиради, лекин асосий ўқишни имтиҳон тилида олиб бориш керак.
